# 漫画制作の共通手順

既存の本編制作で使った方法を、説明用漫画にも適用する。

参照した制作記録:

- `reports/story-conversation-v5-20261017/cast-and-lettering.txt`
- `reports/story-conversation-v5-20261017/qa-local-k.json`
- `reports/story-seal-v6-20261018/` の台詞修正・実画像確認記録

## 読み順（2026-10-20 ユーザー指定）

- 会話はページ・各コマとも **右上の最初の発話から始める**。
- 右から左、上から下へ読む。返答は質問より少し下げ、返答が先に読まれないようにする。
- **左上から始めてよいのは、その場面を説明するナレーション枠だけ**。場所・時刻・時間経過などの場面説明に限る。
- 場面説明の枠を左上に置いたコマも、会話そのものは右上から始める。
- 「右から左」とプロンプトに書いただけで合格にしない。実画像の位置を確認する。

## 制作と確認

1. コマごとに、台詞全文・発話順・話者を先に確定する。
2. 各コマで最初の発話の位置と、返答・場面説明の位置を指定する。
3. 人物の見た目と持ち物を固定する。既存の吹き出し位置に台詞を押し込めず、必要ならカメラ位置やコマ内の構図を直す。文字を含む画像の左右反転は使わない。
4. 吹き出しは話者ごとに分け、尾を本人の口へつなぐ。画面外の話者は、その人物のいる方向へ尾を出す。顔・手・ゲームの重要部分を覆わない。
5. 実画像を台本と照合し、台詞の欠落・余分な台詞・話者・尾・読み順・カードや盤面の連続性をコマ単位で確認する。
6. 問題のある箇所は、正しい部分を保持する局所修正で直し、修正後の実画像を再確認する。
7. 採用画像をプロジェクトへ保存し、画像ハッシュ・原稿・プロンプト・確認結果を記録してからアプリへ反映する。

原稿の位置指定や自動テストは、実画像を目で確認する代わりにはしない。

## 初回説明漫画のページ構成（2026-10-20）

- 準備・王を隠す説明を1ページ。
- 「動き方はカードごとに決まっている」説明を独立した1ページ。2の縦横と3の斜めなど、具体例で比較する。
- 相手の王を取って勝利する場面を独立した1ページ。
- 動きの違いの説明と勝利場面を、同じページへ詰め込まない。
