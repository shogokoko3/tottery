# 召喚建築 v3

門の内部は [内部空間 v4](summon-interior-v4.md) で各エリア専用の建築・景観に更新。以下は外観を刷新した際の記録。

GitHub main e2fd3a8を基準に作成。素朴な石段・柱・門を背景へ重ねる構成を、建築全体を描いた7枚のイラストへ置き換えた。

## 画材

`assets/skins/summon/art-v3/*.webp` は原画1024×1536をWebP品質90に変換したもの。生成には組み込み画像生成を使用した。原画・プロンプト・参照と元ファイルの記録は workspace `deliverables/召喚建築リデザイン_v3/` に保存。

## 動き

`src/skins/summon-scene.js` は段の前景に奥行きを付け、2秒で前進/上昇する。柱・門枠の描写を保ち、`summon-architecture.js`の各画像の内側輪郭を境に左右の扉を別メッシュで内側へ開く。固定絵から扉部分を抜いているので、開扉後に元の閉じた扉が残らない。扉の内部は奥へ進む霧と光。

門の提示2秒、開扉3秒、結果カードへの飛行2秒は従来と同じ。結果からエリアを選択し、フォイルがある場合のみ扉表面を金にする。所持データ/購入/抽選の変更なし。

## 読み込み

描画素材が揃うまで「召喚の門を準備中」を表示。最大15秒、画像失敗・WebGL喪失・非表示時は保存済み結果へ進む。1枚/10枚の飛行、昇格完了後のフォイル演出は既存UIを使用。

## 検証

- check-summon-intro: 7エリア/銅金の判定/時間/素材/待機・失敗・切替の検証。
- check-foil-acquisition: 既存の昇格/フォイルタイムラインの維持。
- Webビルド、390×844ブラウザ上の造形・開閉・10枚の結果への到達。

ゲーム本体と確認用プレビューは同じ素材・描画処理を使用する。


## 魔界の門の改訂

空との意匠の重複を避けるため、魔界を黒曜石の角柱・鎖・赤い封印を持つ面取りした角形の門へ変更。新原画は `hell-seal-v4.png`、配信用素材は `hell-seal-v4.webp`。原画一覧と開閉プレビューは新デザインを参照。生成プロンプトは `hell-seal-v4-generation.json`（組み込み画像生成）。旧原画 hell.png は制作記録として保存。ゲーム本体では新しい封印門を使用する。
