# 称号フレーム（2026-09-21）

称号IDから意匠を決め、対戦開始・対戦中の時計欄・ホーム・プロフィール・称号選択・シーズン報酬のプレビューで同じフレームを表示します。通常／布陣／フォイル15キャラ／ガチャの全段階／月間称号に対応します。

- `src/ui/title-design.js`: 称号ごとの紋章・配色・装飾段階。ガチャの上位段階ほど装飾が増え、召喚の7〜9段階も宝石数で区別します。
- `src/ui/title-frame.jsx` / `title-frame.css`: SVGの紋章・左右の彫刻・金属の縁・宝石。追加の画像通信はありません。対戦中は静止し、称号選択の大きなプレビューだけ光が流れます。演出OFF・OSの動きを減らす設定では停止します。
- 長い称号は折り返し、月間称号は年月と称号を分けて表示します。時計欄は名前／時計の下にフレーム用の1行を設けています。
- 獲得条件・手動受取・保存・通信の仕様は変更しません。未取得のシークレット、未解放フォイル、未取得のガチャ4段目以降を隠す既存ルールも維持します。未知の称号IDは何も表示しません。

確認: `node tools/check-title-frames.mjs` と既存の称号・ガチャ称号・フォイルミッション検査。`node tools/serve-title-frames-check.mjs` で [ローカル一覧](http://127.0.0.1:4263) を開けます。実際の対戦表示部品と称号選択を使い、保存とプロフィール更新は確認用に隔離しています。本番へ通信しません。確認用の一覧には未公開段階・シークレットを含め、全デザインを掲載しています。

検証済み: 全80種×3サイズの描画、未知のID、段階ごとの意匠、320px／390pxの対戦・プロフィール表示、選択と決定、未取得の装備禁止と非公開称号の除外。称号・ガチャ称号・フォイルミッション・時計・サイコロ・ホーム配置・演出設定の既存検査とビルドは通過しています。

既存の `tools/check-season.mjs:155` は同じ対局の指紋を使った10件を10戦と期待するため、重複排除によって1戦となり失敗します。今回の変更前の HEAD（8a2ca1d）を一時ディレクトリに展開した検査でも同じ失敗を確認しました。シーズン集計処理は変更していません。
