# 称号フレーム（2026-09-21）

保存版の一覧は `node tools/serve-title-frames-check.mjs --export` で `reports/title-frames/index.html` に書き出せます。画像・スクリプト・スタイルを内包し、ブラウザでファイルを直接開けるため、確認用サーバーの停止後も全デザインと対戦表示を見られます。

称号IDから意匠を決め、対戦開始・対戦中の時計欄・ホーム・プロフィール・称号選択・シーズン報酬のプレビューで同じフレームを表示します。通常／布陣／フォイル15キャラ／ガチャの全段階／月間称号に対応します。

- `src/ui/title-design.js`: 称号ごとの紋章・配色に加え、入手条件に応じて装飾を6段階（素朴・彫金・宝飾・荘厳・絢爛・極煌）に設定します。初級は細い金属枠、上位は多重の縁・翼状の彫刻・大型宝石、最上位は冠と放射状の装飾を加えます。同じ系列では達成条件が重いほど装飾が減らず、召喚の7〜9段階も宝石数で区別します。
- フォイル称号の装飾は元スキンのレア度で統一（R:3、SR:4、SSR:5）。月間TOP10:4、TOP3:5、月間1位:6、フォイル全15種・重い収集実績の最終段階も6です。難易度は入手条件を基にした意匠上の目安で、排出率や獲得条件を変更するものではありません。
- `src/ui/title-frame.jsx` / `title-frame.css`: SVGの紋章・左右の彫刻・金属の縁・宝石。追加の画像通信はありません。対戦中は静止し、称号選択の大きなプレビューだけ光が流れます。演出OFF・OSの動きを減らす設定では停止します。
- 長い称号は折り返し、月間称号は年月と称号を分けて表示します。時計欄は名前／時計の下にフレーム用の1行を設けています。
- 獲得条件・手動受取・保存・通信の仕様は変更しません。未取得のシークレット、未解放フォイル、未取得のガチャ4段目以降を隠す既存ルールも維持します。未知の称号IDは何も表示しません。

確認: `node tools/check-title-frames.mjs` と既存の称号・ガチャ称号・フォイルミッション検査。`node tools/serve-title-frames-check.mjs` で [ローカル一覧](http://127.0.0.1:4263) を開けます。最初の「難易度ごとの違い」で6段階を比較できます。実際の対戦表示部品と称号選択を使い、保存とプロフィール更新は確認用に隔離しています。本番へ通信しません。確認用の一覧には未公開段階・シークレットを含め、全デザインを掲載しています。
