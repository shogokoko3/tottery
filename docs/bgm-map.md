# BGM の現状と、足す候補(2026-09-22)

対応表は [src/audio/tracks.js](../src/audio/tracks.js) の1か所。画面の曲は `SCREEN_TRACK`、対局中は `PHASE_TRACK`、
場面で差し替わるものは `EXTRA_TRACKS`。書き忘れは `node tools/check-bgm.mjs`(`npm run check`)が知らせる。

## 1. いま鳴っている曲(7本)

| 曲 | 曲名 / 出どころ | 鳴る場面 |
| --- | --- | --- |
| `title` | 古の碑石 / 甘茶の音楽工房 | タイトル、ホーム、対戦する、ルール設定、チュートリアル一覧、ランキング、ガチャ・スキン、ミッション・バトルパス、カード、お知らせ、ショップ |
| `waiting` | ジェーン・グレイの肖像 / 甘茶 | ランダムマッチの待ち、合言葉ルーム、近くの端末を探す。**引き分けの決着画面**もこれ |
| `setup` | 深い闇の奥で / 甘茶 | 対局の開始〜サイコロ・引き直し・布陣・王選び。詰めトッタリーも |
| `battle` | 斜塔 / 甘茶 | 対局本編 |
| `endgame` | 騎兵戦 / 甘茶 | 終盤(どちらかの残り時間が1分を切る、または盤の駒が4割未満)。一度入ったら戻らない |
| `win` | ジングル01 / 魔王魂 | 勝ちの決着。ループしない(4秒) |
| `lose` | ジングル07 / 魔王魂 | 負けの決着。ループしない(5秒) |

決めごと:
- 対局の外の画面はすべて `title` で通す。**画面を行き来しても曲が切れない**ため
- 終盤の判定は**公開情報だけ**(持ち時間・盤の駒数)。王の危険で曲を変えると伏せた王の正体が漏れる
- チュートリアル中は音量 0.55 倍(`TUTORIAL_VOLUME`)
- 魔王魂は「音楽：魔王魂」の表記が規約で必須(設定画面の `MUSIC_CREDIT`)

### 曲を止めずに下げる(duck)場面

駒を取った瞬間(0.7秒)、スキンの映像、A の魔法、盤面エリアの発動、召喚(ガチャ)の9秒、凍結演出、バトルパスの魔法。
これらは自前の合成音か映像の音を重ね、終わると曲が戻る。

### 効果音(6本)

`place`(置く・動く。自分の手だけ)、`capture`(倒れる。両者)、`tick`(残り時間の区切り)、`aceSwap` / `aceCapture`(A の入れ替え・包囲)、`aceFoil`(A のフォイル魔法)。
盤面エリアと召喚・凍結は合成音(`area-sounds.js` / `summon-sound.js` / `freeze-sound.js`)。

## 2. 入れたほうがいい場所(優先順)

### 2-1. 決着画面のジングルのあと ★最優先

勝ち負けのジングルが4〜5秒で終わると、**そのあとが無音**。終局画面では熟練度メーター・経験値・称号・撃破札の演出が続き、
いちばん長く見る画面のひとつなのに音が無い。ジングルのあとに**静かな余韻の曲(ループ)**へつなぐ。

- 案A: 勝ち用・負け用で2本(気分が変わる)
- 案B: 穏やかな1本を共通(手間が少ない。まずこちらでよい)
- 作り: `TRACKS` に `after` を足し、`player.js` でループ無し曲の終了時に次の曲へ移る仕掛けを1つ足す(いまは終わると無音のまま)

### 2-2. 引き分け

いまは待合室の `waiting` が流れる。結果画面で待ちの曲は意味がずれている。2-1 の余韻の曲に寄せる(`trackForScene` の draw の分岐を直すだけ)。

### 2-3. ガチャ(召喚)

召喚の9秒はタイトル曲を下げて合成音だけ。結果が開くとタイトル曲に戻る。
- 曲を足すなら「召喚〜結果」を通した1本。ホームと同じ曲のまま引く今より場面が立つ
- ただし先に欲しいのは**結果が開いた瞬間の一発音**(効果音)。SSR 昇格・凍結は合成音があるが、開く瞬間は無音

### 2-4. チュートリアル

曲は対局と同じで音量だけ下げている。第1話は初めての人がいちばん長く聞く曲なので、専用の穏やかな1本があると「教わっている」空気になる。優先度は中。
`useGameBgm` に `tutorial` は既に渡っているので、`trackForScene` で振り分けを足せば済む。

## 3. 入れられるが、無くてもよい場所

- **ガチャ・スキン画面だけ別の曲**にする案。買い物の場所として区別できる。ほかのホーム系はタイトル曲のままでよい
- **盤面エリアごとの曲**(海・氷・森・土・空・宮殿)。エリアは王のスキンで立つので、曲を変えると**王の正体のヒント**になり得る。
  エリア自体は両者に見えているので原理上は漏れないが、入れる前に確認が要る
- **詰めトッタリー専用**。いまは布陣の曲。考える場面なので今のままで悪くない

## 4. BGM より先に、効果音の空白

次の場面には音が無い。BGM より先にここへ一発音を足すほうが体感は上がる。

| 場面 | いま |
| --- | --- |
| ログインボーナスの受け取り | 無音 |
| ミッションの受け取り(1件・一括) | 無音 |
| レベルアップ(経験値ゲージが満ちる) | 無音 |
| 称号・布陣称号の授与 | 無音 |
| フォイルの獲得・開封 | 無音 |
| 詰めトッタリーの正解・クリア | 無音(駒の音だけ) |
| 召喚の結果が開く瞬間 | 無音(9秒の合成音のあと) |
| 釦の押下全般 | 無音 |

効果音ラボの音は表記不要・アプリ内蔵可。`tools/prepare-se.mjs` で使う部分だけ切り出して `SOUNDS` に足す。
効果音は解錠時に全部読むので、増やしすぎると起動が重くなる(いまは6本で数十KB)。

## 5. 足すときの手順

1. 原曲を `assets/audio/原曲/` に置き、`tools/bgm-list.mjs` の表に出どころを書く
2. `node tools/prepare-bgm.mjs` でループできる形に整える(音量は −20dBFS にそろう)。継ぎ目は `tools/bgm-seam.mjs` で聴く
3. `TRACKS` に1行足し、`SCREEN_TRACK` / `PHASE_TRACK` / `EXTRA_TRACKS` のどれかに載せる
4. `node tools/check-bgm.mjs`。場面ごとの音量の釣り合いは音源ではなく `gain` で決める
5. 出どころが魔王魂なら表記はいまの `MUSIC_CREDIT` で足りる。別の出どころなら規約を読んで `MUSIC_CREDIT` に足す
