# アプリ内BGM・SE（2026-10-19）

BGM16曲・SE60種類を候補集から選定して同梱。Runwayの生成音源を採用し、追加生成はしていない。
再生URLはすべてアプリ相対パス。音声のための外部接続やOS通知音は使わない。

## SEと再生設定

共通操作、サイコロ、配札、駒配置/移動/撃破、王選択、時間警告、Aの魔法、公開エリア、アリスの可視演出、召喚/凍結/レア別出現/フォイル、ログイン/ミッション/レベルアップ/称号/熟練度、錬成/分解/装備/購入/フレンド承認、詰めの正解/不正解に接続。
勝敗と引き分けは短いSEを一度鳴らし、それぞれの余韻BGMをループする。
領域別のBGMは今回未採用。対局の読み合いと曲の連続性を優先した。
音量は既存のBGM/SE設定と消音を共有。動画・召喚・凍結の音もSEバスを使う。
背景ではBGMと発音中SEを停止し、復帰時に現在のBGMを再開する。
同一SEの100ms以内の連打を間引く。同時発音は8つまで。読込は最大4並列。
未読込SEは180ms以内に読み終わる場合だけ再生し、遅れた効果音を防ぐ。

## 伏せ情報

王選択は自分側の変化だけで鳴らす。相手の非公開の操作を音にしない。
迷いの森の時計非表示中は時間警告を抑止。終盤BGMも非公開の残り時間では判定しない。
公開された盤上の駒数による終盤判定は継続する。

## 音源処理と検証

`tools/prepare-selected-audio.mjs`で元MP3から再処理できる。元候補は隣の候補集フォルダに保持。
BGM：無音/終端フェードを整理し1.3秒クロスフェードでループ化、-23dBFS RMS、96kbps AAC。
SE：無音整理と4msの端処理、-19dBFS RMS、64kbps AAC。ピーク上限はいずれも-2dBFS。
制作元・尺・容量は`selected-audio.json`。ビルドは参照中の音源だけを`dist/audio`へ出力する。
`check-bgm`、`check-bgm-playback`、`check-app-audio`が通過。
全体チェックはNode24で実行。音とは無関係の既存ストーリー本文検査2件と承認記録欠落1件が失敗。
Web画面の遷移、設定表示、音源読込エラーがないことを確認。全候補の聴感比較審査と実機スピーカーでの最終確認は未実施。
iOS/Androidの同梱データへ同期。ストア送信と実機インストールは未実施。

## 2026-10-20 SEの高音見直し

26種類のベル・ガラス調の決定/報酬/出現音を、持続音のない短い木・紙の音へ置換。残り34種類は狭い帯域の共鳴と高域を抑制。
撃破の追加合成音も700Hz超の発振と高域のノイズを除き、低い打撃音を短く残す。
動画・エリアを含むSEバスだけに、1.4kHzから-6dBの棚型フィルターと3.2kHzの穏やかなローパスを設定。BGMは変更しない。
旧SEは`reports/se-soft-20261020/originals`、処理記録は`analysis.json`、試聴は`見直し後_SE試聴.wav`。再処理は`python3 tools/soften-se.py`。
