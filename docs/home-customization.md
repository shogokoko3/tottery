# ホームの着せ替え

設定の「ホームの着せ替え」から、標準と7エリアのホーム装飾を選ぶ。
承認済みの背景・王のイラスト・各エリア固有のフレームを使い、既存の残高、
プレイヤー情報、通知、各メニューの動作をそのまま表示する。

## 解放条件

| 装飾 | 対応するフォイル        |
| ---- | ----------------------- |
| 土   | 2・3のいずれか          |
| 海   | 4・5のいずれか          |
| 森   | 6・7のいずれか          |
| 氷   | 8・9のいずれか          |
| 空   | 10                      |
| 天界 | 天使のJ・Q・Kのいずれか |
| 魔界 | 悪魔のJ・Q・Kのいずれか |

入手経路は問わず、すでに持っているフォイルも対象。装備・王への指定は不要。
`areaRewardsFor`と対応を共有する。Aのフォイルはこの7エリアには対応しない。
未解放でも見本と条件を確認できるが適用できない。標準は常に使用可能。

土・海・森・氷のキャラも、2〜9それぞれの所持フォイルと対応する。
3のみ所持なら女性ゾンビ、6のみなら男性エルフなど、獲得した本人を表示する。
そのエリアの2キャラを所持していれば好きな方を選べる。
天界・魔界のキャラは、所持するJ・Q・Kそれぞれのフォイルと対応する。
Jだけ所持していればJ、QだけならQを表示し、未所持のKを使用できない。
複数を所持している場合は、着せ替え画面の「ホームに迎えるキャラ」で選べる。
全15キャラに、風景とキャラを一枚に描いた横長のホーム専用挿絵を使う。
承認済みの7枚（土2・海4・森7・氷9・空10・天界K・魔界K）はそのまま使用する。
残り8キャラは、各エリアの承認済み構図と光に合わせた専用イラストを使う。
カード用の縦長イラストを拡大して代用しない。ホーム本体・着せ替え見本・サムネイルで同じ挿絵を参照する。
背景とフレームはエリアで共通。キャラの名前もイラストに合わせる。
選んだキャラは`collection.homePortraits`にエリアごとに保存する。
一度決まったキャラは、別のフォイルを獲得しても勝手に変更しない。

獲得時は自動変更せず、本人が選んだ装飾だけを`collection.homeTheme`に保存する。
選択は現在のスキン所持情報と同じ端末の保存領域を使う。通貨・所持品・獲得結果は
変更しない。保存時も最新の所持状態を再確認する。未獲得や不正な選択は標準へ戻す。
最後のフォイル1枚は既存仕様で分解できないため、所持情報から解放を判定する。

## 表示・検証

ホームの着せ替え専用ボタンは置かず、右上の設定または自分のプレイヤー情報から開く。
プレイヤー情報とお知らせは同じ段に配置し、通貨・チケットは残高バーにまとめる。
対戦ボタンの下に各メニューを2列で並べ、イラストは横長の全景を維持する。
ホーム本体は動的ビューポートの高さに固定し、ページをスクロールさせない。
ヘッダーの実際の高さを除いた残りへ配置し、下の安全領域はホーム内で一度だけ確保する。
標準ホームはイラストの空きを残さず、2列3段のメニューを広げて画面を使う。
着せ替えホームでは高さが足りない分だけ挿絵を縮め、全景と操作ボタンを残す。
小型画面ではアイコンと文字を横並びにし、ボタンの押せる高さを44px以上確保する。
ホーム以外の画面とダイアログ内部のスクロールは制限しない。

ダイアログは一覧だけスクロールし、上部の閉じる・下部の戻ると適用は常時表示する。
装飾画像・四隅・縁は操作を遮らず、文字の背景に不透明なパネルを敷く。
`assets/skins/home-v1/`のWebP22点（`characters/`内の追加8点を含む）とSVG21点を通常のビルドで配布する。

`tools/check-home-themes.mjs`でフォイルの対応、未獲得制限、保存・復元、通貨の保持、
獲得時の自動切替がないことを確認する。画面はスマートフォンの幅で別途確認する。
