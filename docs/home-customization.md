# ホームの着せ替え

ホーム上部または設定の「着せ替え」から、標準と7エリアのホーム装飾を選ぶ。
承認済みの背景・王のイラスト・各エリア固有のフレームを使い、既存の残高、
プレイヤー情報、通知、各メニューの動作をそのまま表示する。

## 解放条件

| 装飾 | 対応するフォイル        |
| ---- | ----------------------- |
| 土   | 2・3のいずれか          |
| 海   | 4・5のいずれか          |
| 森   | 6・7のいずれか          |
| 氷   | 8・9のいずれか          |
| 空   | 10                      |
| 天界 | 天使のJ・Q・Kのいずれか |
| 魔界 | 悪魔のJ・Q・Kのいずれか |

入手経路は問わず、すでに持っているフォイルも対象。装備・王への指定は不要。
`areaRewardsFor`と対応を共有する。Aのフォイルはこの7エリアには対応しない。
未解放でも見本と条件を確認できるが適用できない。標準は常に使用可能。

獲得時は自動変更せず、本人が選んだ装飾だけを`collection.homeTheme`に保存する。
選択は現在のスキン所持情報と同じ端末の保存領域を使う。通貨・所持品・獲得結果は
変更しない。保存時も最新の所持状態を再確認する。未獲得や不正な選択は標準へ戻す。
最後のフォイル1枚は既存仕様で分解できないため、所持情報から解放を判定する。

## 表示・検証

ダイアログは一覧だけスクロールし、上部の閉じる・下部の戻ると適用は常時表示する。
装飾画像・四隅・縁は操作を遮らず、文字の背景に不透明なパネルを敷く。
`assets/skins/home-v1/`のWebP14点とSVG21点を通常のビルドで配布する。

`tools/check-home-themes.mjs`でフォイルの対応、未獲得制限、保存・復元、通貨の保持、
獲得時の自動切替がないことを確認する。画面はスマートフォンの幅で別途確認する。
