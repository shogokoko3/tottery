# 使っている第三者のソフトウェア

配布物(`index.html`)には React が含まれる。いずれも MIT ライセンスで、
配布のさいにライセンス表示を求めている。

| 名前 | 用途 | ライセンス |
| --- | --- | --- |
| React / React DOM | 画面の組み立て。**配布物に含まれる** | MIT |
| esbuild | 1枚の HTML にまとめる。開発時のみ | MIT |
| Babel (parser / traverse / generator / types) | ソースの分割。開発時のみ | MIT |
| Prettier | 書式を整える。開発時のみ | MIT |
