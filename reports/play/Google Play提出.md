# Google Play 提出用の文章と答え(2026-09-19)

Play Console に貼るための下書き。文字数は Google の上限に収めてある。
iOS 版の下書きは `reports/appstore/App Store提出.md`。中身は同じゲームだが、
**Play は欄も申告も別物**なので、流用せずここから貼ること。

いまの状態: Android 版は**課金・広告・近くの端末との対戦を出していない**。
申告もそれに合わせて書いてある。あとで課金や広告を入れるときは、
下の「あとで変えるところ」を見て直す。

## 1. 本人しかできない準備(順番に)

1. **Play Console の登録**(https://play.google.com/console) … 登録料 **$25**(一度きり)
   - アカウントの種類は **個人**(法人にすると D-U-N-S 番号が要る)
   - 本人確認: 身分証と住所。**数日かかることがある**ので最初にやる
2. **クローズドテストの要件** … 個人アカウントは、製品版を出す前に
   「一定人数のテスターが一定日数、続けてテストに参加していること」が要る。
   **人数と日数は Console の「製品版」の画面に出ているものが正**(Google が何度か変えている)。
   日数が固定でかかるので、アプリの形ができた時点ですぐ始める
3. **アプリを作る** … Console 左上「アプリを作成」
   | 欄 | 値 |
   | --- | --- |
   | アプリ名 | トッタリー |
   | 言語 | 日本語 |
   | アプリかゲームか | **ゲーム** |
   | 無料か有料か | **無料**(あとから有料にはできない) |
4. **アップロード鍵を作る**(`Android配信.md` の「署名」)。パスワードは自分で決めて控える
5. **AAB を上げる** … `npm run android:bundle` の出力を「テスト → 内部テスト」へ

## 2. ストアの掲載情報

### アプリ名(30字まで)

```
トッタリー
```

### 簡単な説明(80字まで)

```
配られた札で陣を組み、隠れた王を討つ。二人対戦の心理戦ボードゲーム。
```

### 詳しい説明(4000字まで)

```
トッタリーは、毎回ランダムに配られたトランプの札で陣形を組み、
相手の隠された王を討つ、二人対戦の心理戦ボードゲームです。
配られた札から軍を組み、自陣に並べ、王を一枚選ぶ。王はお互いに伏せたまま。
動きから相手の王を読み、自分の王は読まれないように動かす。相手の王を討てば勝ちです。

■ 札ごとに動きが違う
2は縦横に1マス、3は斜めに1マス。6と8は偶数・奇数のマスをまとめて取り、
10は跳び、Jは縦横、Qは斜めに果てまで走ります。Kは全部の動きができる代わりに、
JとQを1枚ずつしか置けません。Aは動けませんが、盤の駒を入れ替える力があります。

■ どれが王かは、相手には見えない
王は伏せたまま。ふつうの駒より遠くへ動ける王の力を使えば強いが、動けば正体が知れる。
取られた駒が同じ数字の仲間を道連れにしたり、王が倒れても同じ数字の駒が王位を継いだり。
相手の王がどれかを読み合う駆け引きが、このゲームの軸です。

■ 5×5の短期戦と、9×9の本格戦
5枚で戦う5×5はひと勝負が数分。9枚で戦う9×9は、布陣の組み方から勝負が始まります。
配られる札は毎回違うので、同じ陣形は二度と組めません。
数字を並べたストレート、マークをそろえたフラッシュの布陣ボーナスも。

■ 遊び方は13話のチュートリアルで
第1話から順に、1話につき1つだけ新しいことを覚えます。読むより先に指す作りなので、
説明書は要りません。第8話まで終えると、ランダムマッチが開きます。

■ 対戦のかたち
・CPUと対戦(強さの違う相手、エリアごとの練習相手も)
・フレンドと合言葉でルーム対戦
・ランダムマッチ(持ち点と月間ランキングに数えます)
・1台の端末で交互に指す対戦
・詰めトッタリー(毎朝5時に更新される一日一問)

■ 王のスキンで、盤が変わる
ガチャで手に入るフォイルのスキンを王にすると、9×9の盤に「エリア」が立ちます。
相手の駒の正体を見抜く土、敵を中央へ引き寄せる海、駒を凍らせる氷、
変身する空、昇格する宮殿。それぞれの定石を組み立てる楽しみがあります。

■ 称号とランキング
対局数や布陣の型で称号が手に入り、相手に見せることができます。
月ごとのシーズンでは順位に応じて報酬も。

通信対戦の相手の名前は本名ではなくニックネームです。
不適切な相手は通報・ブロックできます。

すべて無料で遊べます。アプリ内購入も広告もありません。
```

## 3. アプリのコンテンツ(左メニュー「ポリシー」→「アプリのコンテンツ」)

### プライバシーポリシー

`https://tottery.tsmanager.workers.dev/privacy` を貼る。

### 広告

**「いいえ、このアプリには広告が含まれていません」**

Android 版は広告を出さない。ネイティブのプラグインも入れていないので、
`AD_ID`(広告 ID)の権限も入っていない(`capacitor-config.md`)。

### アプリのアクセス権

**「すべての機能が制限なく利用できます」**

ログインもアカウント作成も要らない。名前を決めればすぐ遊べる。

### 対象ユーザーと年齢

- 対象年齢層: **13歳以上**(13-15 / 16-17 / 18歳以上)

### 政府関連アプリ / 金融商品 / 健康 / DSA のトレーダー申告

- 政府関連: いいえ
- 金融商品: いいえ
- 健康: いいえ
- **DSA のトレーダー申告**: 課金が無いあいだは「トレーダーではありません」。
  課金を入れて EU で配るなら「トレーダー」になり、住所・電話・メールが
  製品ページに公開される。自宅住所を出したくなければ、公開用の住所を
  用意するか **配信国から EU を外す**(iOS 側と同じ判断)。

## 4. あとで変えるところ

Android 版に課金・広告・近接対戦を入れるときは、次を直す。

| 何 | どこ |
| --- | --- |
| 詳しい説明の「すべて無料で遊べます。アプリ内購入も広告もありません。」 | この文書と Play Console |
| 広告の申告 | 「はい、広告が含まれます」に |
| データ セーフティ | 広告 ID・購入履歴を足す |
| コンテンツ レーティング | 「デジタル購入」を「はい」に(アンケートをやり直す) |
| ガチャの確率表示 | Play は「有料のランダム化された仮想アイテム」に確率の明示を義務づけている(画面にはすでにある) |
| `capacitor.config.json` | `android.includePlugins` に使うプラグインを足す(`capacitor-config.md`) |
